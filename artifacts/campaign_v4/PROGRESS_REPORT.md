## 1. Architecture Audit Summary

Six defects identified in the pre-existing LEGR implementation:

| ID | Defect | Severity | Status |
|----|--------|----------|--------|
| D-001 | Node features are arbitrary integer IDs, not tool-name text embeddings | Critical | **FIXED** — `encoders_v2.py` with `TextNodeFeatureEncoder` |
| D-002 | `use_text_node_features` flag is dead code (passes zeros) | Critical | **FIXED** — V2 architecture uses real MiniLM embeddings |
| D-003 | Default GNN is undirected (bidirectional=True) | Critical | **FIXED** — V2 defaults to directed, legacy preserved |
| D-004 | CUDA latency benchmark doesn't sync | Medium | Documented, deferred |
| D-005 | No structural-twin distractors in dataset | Critical | **FIXED** — 100% twin coverage |
| D-006 | No automated leakage check | High | **FIXED** — 30/30 validation tests |

## 3. Model Architecture

### Legacy (preserved for reproducibility)
- `LEGRDualEncoder` in `src/encoders.py`
- `nn.Embedding(num_tools, 64)` for node features
- GCN/GAT/Directed variants
- Default: bidirectional GCN

### Corrected (Campaign v4)
- `LEGRDualEncoderV2` in `src/encoders_v2.py`
- `TextNodeFeatureEncoder`: frozen MiniLM encodes tool names → 64d node features
- `DirectedTextGraphEncoder`: directed message passing (W_self/W_in/W_out)
- Direction preservation verified: forward vs reversed cosine = 0.95 (< 1.0)

## 4. Pilot Training Results (15-tool, 5 epochs, CPU, seed=42)

| Model | Val Loss | Val R@1 |
|-------|----------|---------|
| LEGR Legacy (no GED) | 2.444 | 0.155 |
| LEGR Legacy (GED=0.10) | 2.495 | 0.151 |
| LEGR Directed (no GED) | 2.696 | 0.135 |
| LEGR Directed (GED=0.10) | 2.740 | 0.135 |
| SBERT-FT (no GED) | 2.671 | 0.142 |
| SBERT-FT (GED) | 2.671 | 0.142 |

**SBERT Heldout Eval:** R@1=0.66, R@3=0.85, R@5=0.89, Tool-set F1=0.842

*Note: These are 5-epoch pilot numbers. Full 100-epoch CUDA training expected to converge much further.*
